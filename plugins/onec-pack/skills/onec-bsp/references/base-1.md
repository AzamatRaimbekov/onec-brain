## БазоваяФункциональность - общий API БСП, которым заменяется 90% самописных хелперов

**Когда использовать:** всегда, когда в коде конфигурации на БСП появляется желание написать «свою» функцию:
прочитать реквизит по ссылке, разложить строку, подставить параметры в текст, сообщить об ошибке у поля,
запустить фоновое задание из формы с прогрессом, сохранить пароль, записать в журнал регистрации, вызвать модуль
необязательной подсистемы. Подсистема обязательная (входит в любую конфигурацию на БСП), её модули доступны всегда.
Ревьюер должен отклонять дубли этих функций в общих модулях проекта.

**Встраивание:** отдельного встраивания в объект не требует. Точки настройки - модуль
`ОбщегоНазначенияПереопределяемый` (раздел 13) и `ОбщегоНазначенияКлиентПереопределяемый`.

Контекст модулей: `ОбщегоНазначения`, `СтроковыеФункции`, `ДлительныеОперации`, `ФайловаяСистема`,
`СтандартныеПодсистемыСервер`, `ЖурналРегистрации` - сервер; `ОбщегоНазначенияКлиент`, `ДлительныеОперацииКлиент`,
`ФайловаяСистемаКлиент`, `ЖурналРегистрацииКлиент` - клиент; `ОбщегоНазначенияКлиентСервер`,
`СтроковыеФункцииКлиентСервер` - везде.

Справочник сигнатур: `api/БазоваяФункциональность.<Модуль>.md`, индекс - `api-index.md`.

### 1. Чтение данных по ссылке и метаданные

| Задача | Вместо | Метод БСП |
|---|---|---|
| Прочитать 1 реквизит по ссылке | `Ссылка.Реквизит` (читает весь объект) | `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Ссылка, "Контрагент")` |
| Прочитать несколько реквизитов | свой запрос | `ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Ссылка, "Код, Наименование, Родитель")` → Структура |
| Реквизиты массива ссылок | цикл с `Ссылка.Реквизит` | `ОбщегоНазначения.ЗначенияРеквизитовОбъектов(Ссылки, "Дата, Номер")` → Соответствие |
| Один реквизит у массива ссылок | цикл | `ОбщегоНазначения.ЗначениеРеквизитаОбъектов(МассивСсылок, "Организация")` |
| Ссылка на предопределенный по имени | `Справочники.X.Y` с риском отсутствия | `ОбщегоНазначения.ПредопределенныйЭлемент("Справочник.ВидыЦен.Оптовая")` (также `ОбщегоНазначенияКлиент.`) |
| Есть ли ссылки на объект | `НайтиПоСсылкам` | `ОбщегоНазначения.ЕстьСсылкиНаОбъект(СсылкаИлиМассив)` |
| Где используется / заменить ссылки | свой поиск | `ОбщегоНазначения.МестаИспользования(...)`, `ОбщегоНазначения.ЗаменитьСсылки(ПарыЗамен, ПараметрыЗамены)` (+`ПараметрыЗаменыСсылок()`) |
| Ссылка реально существует в БД | `Ссылка.ПолучитьОбъект() <> Неопределено` | `ОбщегоНазначения.СсылкаСуществует(Ссылка)` |
| Менеджер по ссылке / полному имени | `Вычислить("Справочники." + Имя)` | `ОбщегоНазначения.МенеджерОбъектаПоСсылке(Ссылка)`, `ОбщегоНазначения.МенеджерОбъектаПоПолномуИмени("Документ.Заказ")` |
| Вид объекта | разбор `Метаданные().ПолноеИмя()` | `ОбщегоНазначения.ЭтоДокумент(МетаданныеОбъекта)`, `ЭтоСправочник`, `ЭтоРегистрСведений`, `ВидОбъектаПоСсылке(Ссылка)` |
| Есть ли реквизит у метаданных | `Метаданные...Реквизиты.Найти` + стандартные | `ОбщегоНазначения.ЕстьРеквизитОбъекта("Организация", МетаданныеОбъекта)` |
| Ссылка на объект метаданных для хранения | строка с полным именем | `ОбщегоНазначения.ИдентификаторОбъектаМетаданных(Метаданные.Документы.Заказ)` / обратно `ОбъектМетаданныхПоИдентификатору` |
| Имя значения перечисления | `XMLСтрока` / свои соответствия | `ОбщегоНазначения.ИмяЗначенияПеречисления(Значение)` |
| Провести список документов | цикл с `Записать(Проведение)` | `ОбщегоНазначения.ПровестиДокументы(Документы)`, проверка `ОбщегоНазначения.ПроверитьПроведенностьДокументов(Документы)` |
| Представление предмета для писем/задач | `Строка(Ссылка)` + тип | `ОбщегоНазначения.ПредметСтрокой(Ссылка)` |

```bsl
// Быстро и с правами текущего пользователя (без прав на таблицу - исключение):
Реквизиты = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Документ, "Организация, Контрагент, СуммаДокумента");
// Через точку и с псевдонимом - через Структуру:
ИНН = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Документ, Новый Структура("ИНН", "Контрагент.ИНН")).ИНН;
```

### 2. Сообщения и ошибки пользователю

| Задача | Вместо | Метод БСП |
|---|---|---|
| Сообщение у поля формы / объекта | `Новый СообщениеПользователю` вручную | `ОбщегоНазначения.СообщитьПользователю(Текст, КлючДанных, Поле, ПутьКДанным, Отказ)` (сервер), `ОбщегоНазначенияКлиент.СообщитьПользователю(...)` (клиент) |
| Накопить много ошибок (по строкам ТЧ) и вывести разом | цикл сообщений | `ОбщегоНазначенияКлиентСервер.ДобавитьОшибкуПользователю(Ошибки, "Объект.Товары[%1].Количество", Текст, "Объект.Товары", ИндексСтроки, ТекстДляНесколькихОшибок)` (индекс с 0, в текст подставляется +1) + `СообщитьОшибкиПользователю(Ошибки, Отказ)` |
| Текст «не заполнено поле» | своя строка | `ОбщегоНазначенияКлиентСервер.ТекстОшибкиЗаполнения("Поле", "Заполнение", "Контрагент")` |
| Убрать реквизит из проверки заполнения | `ПроверяемыеРеквизиты.Удалить(Найти(...))` | `ОбщегоНазначения.УдалитьНепроверяемыеРеквизитыИзМассива(ПроверяемыеРеквизиты, НепроверяемыеРеквизиты)` |
| Assert в коде (ошибка разработчика) | `ВызватьИсключение` с текстом | `ОбщегоНазначенияКлиентСервер.Проверить(Условие, Сообщение)`, `ПроверитьПараметр("МояФункция", "Параметр", Значение, Тип("Строка"))` |
| Подтверждение закрытия формы с изменениями | свой `ПередЗакрытием` с вопросом | `ОбщегоНазначенияКлиент.ПоказатьПодтверждениеЗакрытияФормы(ОповещениеСохранитьИЗакрыть, Отказ, ЗавершениеРаботы)` |
| Оповестить открытые формы об изменении | `Оповестить("Запись_...")` | `ОбщегоНазначенияКлиент.ОповеститьОбИзмененииОбъекта(Ссылка)` |

`ОбщегоНазначенияКлиентСервер.СообщитьПользователю` лежит в области `УстаревшиеПроцедурыИФункции` - в новом коде не использовать.

### 3. Строки

| Задача | Вместо | Метод БСП |
|---|---|---|
| Шаблон «%1 из %2» | конкатенация `+` | `СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(НСтр("ru = 'Документ %1 от %2'"), Номер, Дата)` |
| Разбить строку | `СтрРазделить` + `СокрЛП` + пропуск пустых | `СтроковыеФункцииКлиентСервер.РазложитьСтрокуВМассивПодстрок(Строка, ";", Истина, Истина)` |
| Оставить только цифры (ИНН, телефон) | цикл по символам | `СтроковыеФункцииКлиентСервер.ТолькоЦифрыВСтроке(Значение)` |
| Дополнить нулями слева | `Формат(..., "ЧЦ=..; ЧВН=")` | `СтроковыеФункцииКлиентСервер.ДополнитьСтроку(Значение, 9, "0", "Слева")` |
| Строку в число / дату | `Число()` в Попытке | `СтроковыеФункцииКлиентСервер.СтрокаВЧисло(Строка)` (Неопределено, если не число), `СтроковыеФункцииКлиентСервер.СтрокаВДату(Строка)` |
| Текст из HTML | регулярки | `СтроковыеФункцииКлиентСервер.ИзвлечьТекстИзHTML(HTML)` |
| Проверка GUID | разбор | `СтроковыеФункцииКлиентСервер.ЭтоУникальныйИдентификатор(Значение)` |
| Форматированная строка с жирным/ссылками | ручная сборка `Новый ФорматированнаяСтрока` | `СтроковыеФункции.ФорматированнаяСтрока(НСтр("ru = 'Подробнее <a href = ""%1"">здесь</a>'"), Адрес)` (сервер) |
| Транслит (имена файлов, логины) | своя таблица | `СтроковыеФункции.СтрокаЛатиницей(Значение)` |
| «за январь 2026», «с ... по ...» | свой формат периода | `СтроковыеФункции.ПредставлениеПериодаВТексте(ДатаНачала, ДатаОкончания)` |
| Строка поиска для `ПОДОБНО` | экранирование вручную | `ОбщегоНазначения.СформироватьСтрокуДляПоискаВЗапросе(СтрокаПоиска)` |

### 6. Окружение: клиент, база, режимы

| Задача | Метод БСП |

| Файловая база | `ОбщегоНазначения.ИнформационнаяБазаФайловая()` |
| Подчиненный узел РИБ | `ОбщегоНазначения.ЭтоПодчиненныйУзелРИБ()`, `ЭтоРаспределеннаяИнформационнаяБаза()` |
| Модель сервиса | `ОбщегоНазначения.РазделениеВключено()`, `ДоступноИспользованиеРазделенныхДанных()` |
| Дата сеанса на клиенте (без серверного вызова) | `ОбщегоНазначенияКлиент.ДатаСеанса()` (на сервере - платформенная `ТекущаяДатаСеанса()`) |
| Рабочая дата пользователя | `ОбщегоНазначения.ТекущаяДатаПользователя()`, `РабочаяДатаПользователя()` |
| Режим отладки (`/C РежимОтладки`) | `ОбщегоНазначения.РежимОтладки()` |
| Версия своей библиотеки/конфигурации | `СтандартныеПодсистемыСервер.ВерсияБиблиотеки("СтандартныеПодсистемы")` |
| Внутренний буфер обмена (копирование строк ТЧ между формами) | `ОбщегоНазначения.СкопироватьВБуферОбмена(Данные, Источник)`, `СкопироватьСтрокиВБуферОбмена(...)`, `СтрокиИзБуфераОбмена(...)` |

### 7. Файлы и временные каталоги

| Задача | Вместо | Метод БСП |
|---|---|---|
| Временный каталог на сервере и его удаление | `КаталогВременныхФайлов()+...`, `УдалитьФайлы` | `ФайловаяСистема.СоздатьВременныйКаталог()`, `ФайловаяСистема.УдалитьВременныйКаталог(Путь)`, `УдалитьВременныйФайл(Путь)` |
| Уникальное имя файла | `Новый УникальныйИдентификатор` | `ФайловаяСистема.УникальноеИмяФайла(Имя)` |
| Запуск внешней программы с ожиданием и кодом возврата | `ЗапуститьПриложение` | `ФайловаяСистема.ЗапуститьПрограмму(Команда, ФайловаяСистема.ПараметрыЗапускаПрограммы())` (на клиенте - `ФайловаяСистемаКлиент.`) |
| Загрузить файл с клиента на сервер | `НачатьПомещениеФайла` | `ФайловаяСистемаКлиент.ЗагрузитьФайл(Оповещение, ФайловаяСистемаКлиент.ПараметрыЗагрузкиФайла())` / `ЗагрузитьФайлы` |
| Сохранить файл на клиент | `ПолучитьФайл` | `ФайловаяСистемаКлиент.СохранитьФайл(Оповещение, АдресВоВременномХранилище, ИмяФайла)` |
| Открыть файл / ссылку / проводник | `ЗапуститьПриложение` | `ФайловаяСистемаКлиент.ОткрытьФайл(...)`, `ОткрытьНавигационнуюСсылку(...)`, `ОткрытьПроводник(...)` |
| Выбрать каталог | `ДиалогВыбораФайла` | `ФайловаяСистемаКлиент.ВыбратьКаталог(Оповещение, Заголовок)` |
| Разобрать путь / расширение / недопустимые символы | `СтрНайти` | `ОбщегоНазначенияКлиентСервер.РазложитьПолноеИмяФайла(Путь)`, `ПолучитьРасширениеИмениФайла(Имя)`, `ЗаменитьНедопустимыеСимволыВИмениФайла(Имя)` |

Клиентские методы `ФайловаяСистемаКлиент` асинхронные (оповещение) и сами решают вопрос с расширением работы с файлами
в веб-клиенте - не вызывайте синхронные `ПолучитьФайл`/`ПоместитьФайл`.

### 8. Настройки пользователя и безопасное хранилище

```bsl
// Пароли, токены, ключи API - только в безопасное хранилище, НЕ в реквизиты справочника/константы.
УстановитьПривилегированныйРежим(Истина);
ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище(ТекущийОбъект.Ссылка, Пароль);           // ключ "Пароль"
ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище(ТекущийОбъект.Ссылка, Токен, "Токен");
УстановитьПривилегированныйРежим(Ложь);
...
УстановитьПривилегированныйРежим(Истина);
Данные = ОбщегоНазначения.ПрочитатьДанныеИзБезопасногоХранилища(Ссылка, "Пароль, Токен");      // Структура
УстановитьПривилегированныйРежим(Ложь);
// При удалении владельца: ОбщегоНазначения.УдалитьДанныеИзБезопасногоХранилища(Ссылка);
```
- Владелец - ссылка на объект или строка до 128 символов (`"МояПодсистема.ИнтеграцияCRM"`).
- Пользовательские настройки: `ОбщегоНазначения.ХранилищеОбщихНастроекСохранить(КлючОбъекта, КлючНастроек, Значение)` /
  `ХранилищеОбщихНастроекЗагрузить(КлючОбъекта, КлючНастроек, ПоУмолчанию)` (и одноименные в `ОбщегоНазначенияКлиент`) -
  ключ длиннее 128 символов хешируется; при отсутствии права `СохранениеДанныхПользователя` запись молча пропускается.
  Аналоги: `ХранилищеСистемныхНастроек...`, `ХранилищеНастроекДанныхФорм...`.

### 9. Журнал регистрации

- Сервер: платформенный `ЗаписьЖурналаРегистрации(ИмяСобытия, Уровень, Метаданные, Данные, Комментарий)`. Имя события -
  в виде `"МояПодсистема.Действие"`, локализованное на основной язык, как делает сама БСП:
  `НСтр("ru = 'Интеграция.Загрузка заказов'", ОбщегоНазначения.КодОсновногоЯзыка())`.
- Текст ошибки: `ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())` в журнал,
  `ОбработкаОшибок.КраткоеПредставлениеОшибки(...)` пользователю.
- Клиент (без серверного вызова на каждое событие): `ЖурналРегистрацииКлиент.ДобавитьСообщениеДляЖурналаРегистрации(ИмяСобытия, "Ошибка", Комментарий, , Истина)`
  - события копятся и пишутся пакетно (`ЖурналРегистрации.ЗаписатьСобытияВЖурналРегистрации(МассивСобытий)` на сервере).
- Открыть журнал с отбором: `ЖурналРегистрацииКлиент.ОткрытьЖурналРегистрации(Отбор)`.

### 10. Вызов по имени и необязательные подсистемы

Обязательный шаблон БСП для обращения к подсистеме, которой может не быть в конфигурации (в т.ч. в своих библиотеках):
```bsl
Если ОбщегоНазначения.ПодсистемаСуществует("СтандартныеПодсистемы.Свойства") Тогда
	МодульУправлениеСвойствами = ОбщегоНазначения.ОбщийМодуль("УправлениеСвойствами");
	МодульУправлениеСвойствами.ПриСозданииНаСервере(ЭтотОбъект, ДополнительныеПараметры);
КонецЕсли;
// на клиенте: ОбщегоНазначенияКлиент.ПодсистемаСуществует / ОбщегоНазначенияКлиент.ОбщийМодуль
```
- В прикладной конфигурации, где подсистема точно внедрена, прямой вызов `УправлениеСвойствами.ПриСозданииНаСервере`
  допустим; шаблон нужен в коде библиотек и расширений.
- Вызов метода по строке: `ОбщегоНазначения.ВыполнитьМетодКонфигурации("МойМодуль.МояПроцедура", Параметры)` вместо
  `Выполнить(...)` - проверяет, что строка является именем экспортного метода, и учитывает профиль безопасности.
  Для метода объекта - `ОбщегоНазначения.ВыполнитьМетодОбъекта(Объект, "ИмяМетода", Параметры)`.
- Пользовательские формулы/алгоритмы: только `ОбщегоНазначения.ВыполнитьВБезопасномРежиме(Алгоритм, Параметры)` /
  `ВычислитьВБезопасномРежиме(Выражение, Параметры)`; внутри запрещены `Выполнить`, транзакции, `ЗначениеИзСтрокиВнутр`,
  `ДлительныеОперации`, `ОбщийМодуль` и др.
- **Новое в 3.2:** методы, вызываемые по имени (`ВыполнитьМетодКонфигурации`, `ВыполнитьМетодОбъекта`) и запускаемые в фоне
  (`ДлительныеОперации.ВыполнитьФункцию/ВыполнитьПроцедуру/ВыполнитьВФоне`, `ФоновыеЗадания.Выполнить`), следует
  регистрировать в том же модуле:
```bsl
// См. СтандартныеПодсистемыСервер.ПриОпределенииМетодовРазрешенныхДляВызоваКакПроизвольныйКод
Процедура ПриОпределенииМетодовРазрешенныхДляВызоваКакПроизвольныйКод(Методы) Экспорт
	Методы.Вставить("СформироватьДанныеОтчета", Истина); // Истина - можно запускать в фоне
	Методы.Вставить("ПересчитатьЦены");                  // без значения - только вызов по имени, не в фоне
КонецПроцедуры
```
  В 3.2.1.541 проверка в рантайме выключена (`СтандартныеПодсистемыСервер.ПроверятьВызовыМетодовКакПроизвольныйКод()`
  возвращает Ложь), но отчет ПроверкаВнедренияБСП уже выдает ошибки - добавляйте процедуру сразу.

### 11. Длительные операции (фоновые задания из формы)

**Когда:** любая операция дольше 1-2 сек из формы (формирование, загрузка, расчет). Заменяет самописные
`ФоновыеЗадания.Выполнить` + `ПодключитьОбработчикОжидания` + опрос состояния; даёт окно ожидания, прогресс, отмену,
передачу сообщений из фона, работу в файловой базе.

```bsl
// 1. Экспортная функция в модуле менеджера / серверном общем модуле (параметры и результат - сериализуемые):
Функция РассчитатьЗначение(Знач Параметр1, Знач Параметр2) Экспорт
	ДлительныеОперации.СообщитьПрогресс(50, НСтр("ru = 'Обработано 50%'"));
	Возврат Результат;
КонецФункции

// 2. Форма:
&НаКлиенте
Процедура Рассчитать(Команда)
	ДлительнаяОперация = НачатьРасчетНаСервере();
	ОповещениеОЗавершении = Новый ОписаниеОповещения("РассчитатьЗавершение", ЭтотОбъект);
	ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(ЭтотОбъект);
	ПараметрыОжидания.ТекстСообщения = НСтр("ru = 'Выполняется расчет...'");
	ПараметрыОжидания.ВыводитьПрогрессВыполнения = Истина;
	ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация, ОповещениеОЗавершении, ПараметрыОжидания);
КонецПроцедуры

&НаСервере
Функция НачатьРасчетНаСервере()
	ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
	ПараметрыВыполнения.НаименованиеФоновогоЗадания = НСтр("ru = 'Расчет значения'");
	Возврат ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения,
		"Обработки.МояОбработка.РассчитатьЗначение", Объект.Параметр1, Объект.Параметр2);
КонецФункции

&НаКлиенте
Процедура РассчитатьЗавершение(Результат, ДополнительныеПараметры) Экспорт
	Если Результат = Неопределено Тогда // отменено пользователем
		Возврат;
	ИначеЕсли Результат.Статус = "Ошибка" Тогда
		СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(Результат.ИнформацияОбОшибке);
		Возврат;
	КонецЕсли;
	Значение = ПолучитьИзВременногоХранилища(Результат.АдресРезультата);
КонецПроцедуры
```
- Процедура без результата: `ДлительныеОперации.ВыполнитьПроцедуру(ДлительныеОперации.ПараметрыВыполненияПроцедуры(), "Модуль.Процедура", ...)`.
- Процедура, которая сама кладет результат по адресу: `ДлительныеОперации.ВыполнитьВФоне(ИмяПроцедуры, ПараметрыПроцедуры, ДлительныеОперации.ПараметрыВыполненияВФоне(УникальныйИдентификатор))`.
- Параллельная обработка порций: `ДлительныеОперации.ВыполнитьФункциюВНесколькоПотоков(ИмяФункции, ПараметрыВыполнения, НаборПараметров)`.
- Ключ `КлючФоновогоЗадания` - запрет двойного запуска; `ЗапуститьВФоне = Истина` - всегда в фоне;
  `ОжидатьЗавершение = 0` - сразу вернуть управление.
- Без формы (обработчик ожидания, проверка): `ДлительныеОперации.ЗаданиеВыполнено(Идентификатор)`, `ПрочитатьПрогресс`,
  `ОтменитьВыполнениеЗадания`.
- Модуль обработки: `"Обработка.Имя.МодульОбъекта.Метод"`, менеджер обработки: `"Обработки.Имя.Метод"`.

`СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(ИнформацияОбОшибке)` показывает ошибку фона пользователю
стандартным образом (с возможностью отправить отчет) - не собирайте текст вручную.

### 12. Регламентные задания

```bsl
Процедура ЗагрузкаКурсовПоРасписанию() Экспорт
	ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания(Метаданные.РегламентныеЗадания.ЗагрузкаКурсовВалют);
```

### 13. ОбщегоНазначенияПереопределяемый - точки встраивания

| Процедура | Что заполнять |
|---|---|
| `ПриОпределенииОбщихПараметровБазовойФункциональности(ОбщиеПараметры)` | `МинимальнаяВерсияПлатформы`, `РекомендуемаяВерсияПлатформы`, `ЗапрашиватьПодтверждениеПриЗавершенииПрограммы`, `ВыводитьПолныйСтекПриОшибкеДлительнойОперации` |
| `ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики)` | свои параметры сеанса: `Обработчики.Вставить("ТекущаяОрганизация", "МойМодульСервер.УстановкаПараметровСеанса")` (обработчик получает `ИмяПараметра, УстановленныеПараметры`); сам модуль сеанса не трогать |
| `ПриДобавленииПараметровРаботыКлиентаПриЗапуске(Параметры)` / `ПриДобавленииПараметровРаботыКлиента(Параметры)` | значения, нужные клиенту без серверных вызовов; читать через `СтандартныеПодсистемыКлиент.ПараметрыРаботыКлиента()` |
| `ПриДобавленииИсключенийПоискаСсылок(ИсключенияПоискаСсылок)` | служебные регистры/реквизиты, не мешающие удалению объекта (`ИсключенияПоискаСсылок.Добавить(Метаданные.РегистрыСведений.МойЛог)`) |
| `ПриОпределенииПодчиненныхОбъектов(ПодчиненныеОбъекты)` | объекты, которые заменяются/удаляются вместе с владельцем при объединении дублей |
| `ПриДобавленииПереименованийОбъектовМетаданных(Переименования)` | при переименовании объекта метаданных: `ОбщегоНазначения.ДобавитьПереименование(Переименования, "1.0.5.1", "Справочник.Старое", "Справочник.Новое", Библиотека)` - иначе потеряются настройки/права |
| `ПриОпределенииПоддерживаемыхВерсийПрограммныхИнтерфейсов` | версии своих веб-сервисов |
| `ПриНастройкеПроверкиМетодовВызываемыхКакПроизвольныйКод(Настройки)` | исключения для статической проверки методов по имени |
| `ПриДобавленииСерверныхОповещений`, `ПриПериодическомПолученииДанныхКлиентаНаСервере` | периодические серверные оповещения на клиент вместо своих обработчиков ожидания |

### Подводные камни (БазоваяФункциональность)
- `ЗначенияРеквизитовОбъекта` по умолчанию проверяет права (`ВыбратьРазрешенные = Ложь` → исключение при отсутствии
  права на таблицу/реквизит). Для служебного чтения - `УстановитьПривилегированныйРежим(Истина)` вокруг вызова;
  для «тихого» RLS - `ВыбратьРазрешенные = Истина` (при ограничении вернутся `Неопределено`).
- `ЗначенияРеквизитовОбъектов` для массива ссылок разных типов работает, но делает запрос на каждый тип - в цикле по
  строкам ТЧ вызывайте один раз для всего массива.
- `СообщитьПользователю` нельзя передавать одновременно `КлючДанных` и `ПутьКДанным`; в фоновом задании сообщения доставляются
  через `ДлительныеОперации` (поле `Сообщения` результата), прямой вызов из регламентного задания никуда не выводится.
- Длительные операции: параметры и результат должны быть сериализуемыми (не `ДанныеФормы`, не объекты); параметры функции
  не должны изменяться (не возвращаемые); в файловой базе через внешнее соединение фон не поддерживается - метод выполнится
  синхронно; при закрытии формы-владельца операция отменяется (`ОтменятьПриЗакрытииФормыВладельца`).
- Безопасное хранилище читается/пишется только в привилегированном режиме, который включает вызывающий код - не держать
  привилегированный режим дольше двух строк; не возвращать прочитанный пароль на клиент.
- `ОбщийМодуль("Имя")` с несуществующим именем вызывает исключение - всегда в паре с `ПодсистемаСуществует`.
- `ВыполнитьВБезопасномРежиме` рекомендуется вызывать вне транзакции (тогда код выполнится в транзакции с откатом).
- `ХранилищеОбщихНастроекСохранить` молча ничего не делает у пользователя без права `СохранениеДанныхПользователя` - не
  используйте для данных, которые обязаны сохраниться.

## ВнешниеКомпоненты - подключение Native API/COM компонент с установкой и обновлением
**Когда использовать:** сканеры, ККТ, криптография, свои Native-компоненты. Заменяет `ПодключитьВнешнююКомпоненту` +
`УстановитьВнешнююКомпоненту` с ручной обработкой веб-клиента/ОС: БСП проверяет поддержку клиента, предлагает установку,
кэширует объект, загружает компоненту с портала ИТС, хранит версии в справочнике `ВнешниеКомпоненты`.

**Встраивание (рецепт):**
1. Метаданные: компонента либо в общем макете (ZIP-архив) конфигурации, либо загружается администратором в справочник
   `ВнешниеКомпоненты` (форма загрузки - `ВнешниеКомпонентыКлиент.ЗагрузитьКомпонентуИзФайла`). Переопределяемого модуля нет.
2. Клиент - компонента из справочника:
```bsl
&НаКлиенте
Асинх Процедура ПодключитьСканер()
	ПараметрыПодключения = ВнешниеКомпонентыКлиент.ПараметрыПодключения();
	ПараметрыПодключения.ТекстПояснения = НСтр("ru = 'Для работы со сканером требуется компонента ""InputDevice"".'");
	Результат = Ждать ВнешниеКомпонентыКлиент.ПодключитьКомпонентуАсинх("InputDevice", , ПараметрыПодключения);
	Если Результат.Подключено Тогда
		Сканер = Результат.ПодключаемыйМодуль;
	ИначеЕсли Не ПустаяСтрока(Результат.ОписаниеОшибки) Тогда
		ПоказатьПредупреждение(, Результат.ОписаниеОшибки);
	КонецЕсли;
КонецПроцедуры
```
   Компонента из макета конфигурации: `ОбщегоНазначенияКлиент.ПодключитьКомпонентуИзМакетаАсинх(Идентификатор, "ОбщийМакет.ИмяМакета", Параметры)`;
   на сервере - `ОбщегоНазначения.ПодключитьКомпонентуИзМакета(Идентификатор, "ОбщийМакет.ИмяМакета")`.
3. Сервер - компонента из справочника: `ВнешниеКомпонентыСервер.ПодключитьКомпоненту(Идентификатор, Версия, Параметры)` → Структура (`Подключено`, `ПодключаемыйМодуль`, `ОписаниеОшибки`).

**Главные методы API:** (api/ВнешниеКомпоненты.md)
- `ВнешниеКомпонентыКлиент.ПодключитьКомпонентуАсинх` / `ПодключитьКомпоненту(Оповещение, Идентификатор, Версия, Параметры)`.
- `ВнешниеКомпонентыКлиент.УстановитьКомпонентуАсинх` - только установка (без подключения).
- `ВнешниеКомпонентыКлиент.ПодключитьКомпонентуИзРеестраWindowsАсинх` - COM из реестра.
- `ВнешниеКомпонентыСервер.ПодключитьКомпоненту`, `ИнформацияОКомпоненте(Идентификатор, Версия)`.
- `ОбщегоНазначенияКлиент.ПодключитьКомпонентуИзМакетаАсинх`, `ОбщегоНазначения.ПодключитьКомпонентуИзМакета`.

**Подводные камни:**
- Не храните объект компоненты в реквизите формы - только в переменной модуля формы; БСП кэширует подключение
  (`ПараметрыПодключения.Кэшировать`).
- В модели сервиса на сервере разрешены только общие компоненты, одобренные администратором сервиса.
- `Изолированно` по умолчанию - поведение платформы; падение неизолированной компоненты роняет процесс rphost/клиента.

## ПолучениеФайловИзИнтернета - скачивание файлов и прокси
**Когда использовать:** скачать файл/ответ по http(s)/ftp, получить прокси для своего `HTTPСоединение`. Заменяет
ручное создание соединения без прокси, таймаутов и диагностики; учитывает настройки прокси пользователя и сервера
(константа `НастройкаПроксиСервера`, форма `ПараметрыПроксиСервера`), запрет внешних ресурсов в копии ИБ.

**Встраивание (рецепт):** метаданных и переопределяемых процедур для прикладного кода нет; в интерфейс администрирования
добавить общую команду `ПерсональнаяНастройкаПроксиСервера` или вызов `ПолучениеФайловИзИнтернетаКлиент.ОткрытьФормуПараметровПроксиСервера()`.
```bsl
ПараметрыПолучения = ПолучениеФайловИзИнтернетаКлиентСервер.ПараметрыПолученияФайла();
ПараметрыПолучения.Таймаут = 60;
Результат = ПолучениеФайловИзИнтернета.СкачатьФайлВоВременноеХранилище(URL, ПараметрыПолучения);
Если Не Результат.Статус Тогда
	ВызватьИсключение Результат.СообщениеОбОшибке;
КонецЕсли;
Данные = ПолучитьИзВременногоХранилища(Результат.Путь);

// Свое соединение (REST-API) - но с прокси БСП:
Прокси = ПолучениеФайловИзИнтернета.ПолучитьПрокси("https");
Соединение = Новый HTTPСоединение(Хост, , , , Прокси, 60, ОбщегоНазначенияКлиентСервер.НовоеЗащищенноеСоединение());
```
**Главные методы API:** (api/ПолучениеФайловИзИнтернета.md)
- `ПолучениеФайловИзИнтернета.СкачатьФайлНаСервере(URL, Параметры)` → `Статус, Путь, СообщениеОбОшибке, КодСостояния, Заголовки`.
- `ПолучениеФайловИзИнтернета.СкачатьФайлВоВременноеХранилище(URL, Параметры)` - то же, `Путь` = адрес во временном хранилище.
- `ПолучениеФайловИзИнтернетаКлиентСервер.ПараметрыПолученияФайла()` - `Таймаут, Заголовки, Пользователь, Пароль, ПутьДляСохранения, ...`.
- `ПолучениеФайловИзИнтернета.ПолучитьПрокси(URLИлиПротокол)`, `НастройкиПроксиНаСервере()`.
- `ПолучениеФайловИзИнтернета.ДиагностикаСоединения(URL)` - текст диагностики для пользователя/журнала.

**Подводные камни:** ошибка по умолчанию пишется в журнал регистрации (`ЗаписыватьОшибку = Истина`); в копии ИБ
доступ к интернет-сервисам блокируется (`ПроверятьДоступКИнтернетСервисам`) - не обходите это; пароль для подключения
храните в безопасном хранилище (раздел 8 выше).
