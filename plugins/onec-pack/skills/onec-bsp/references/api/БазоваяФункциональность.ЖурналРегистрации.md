## ЖурналРегистрации
Модуль: Сервер, ВнешнееСоединение

### ЖурналРегистрации.ЗаписатьСобытияВЖурналРегистрации
```bsl
Процедура ЗаписатьСобытияВЖурналРегистрации(СобытияДляЖурналаРегистрации) Экспорт
```
Процедура пакетной записи сообщений в журнал регистрации.
После записи переменная СобытияДляЖурналаРегистрации очищается.

Параметры:
 СобытияДляЖурналаРегистрации - Массив из Структура:
  * ИмяСобытия           - Строка - имя события записи журнала регистрации.
  * ПредставлениеУровня  - Строка - имя значения коллекции УровеньЖурналаРегистрации
                                    "Информация", "Ошибка", "Предупреждение", "Примечание".
  * Комментарий          - Строка - комментарий события записи журнала регистрации.
  * ДатаСобытия          - Дата   - дата события, которая вставляется в начало комментария
                                    (если не заполнена, тогда используется текущая дата сеанса).
