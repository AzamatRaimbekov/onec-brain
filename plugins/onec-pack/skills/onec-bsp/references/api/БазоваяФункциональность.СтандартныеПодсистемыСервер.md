### СтандартныеПодсистемыСервер.УстановкаПараметровСеанса
```bsl
Функция УстановкаПараметровСеанса(ИменаПараметровСеанса) Экспорт
```
Вызов этой процедуры необходимо разместить в модуле сеанса в процедуре УстановкаПараметровСеанса
согласно документации.

Параметры:
 ИменаПараметровСеанса - Массив из Строка
                       - Неопределено - имена параметров сеанса для инициализации.
                                        Массив устанавливаемых идентификаторов параметров сеанса,
                                        которые нужно инициализировать, если обработчик вызывается
                                        перед использованием неинициализированных параметров сеанса.
                                        Неопределено, если обработчик события вызывается системой при начале сеанса.

Возвращаемое значение:
 Массив из Строка - имена параметров сеанса, значения которых были успешно установлены.

### СтандартныеПодсистемыСервер.ЭтоБазоваяВерсияКонфигурации
```bsl
Функция ЭтоБазоваяВерсияКонфигурации() Экспорт
```
Возвращает признак того, является ли конфигурация базовой.
Базовые версии конфигураций могут иметь программные ограничения, действие которых
можно предусмотреть с помощью этой функции.
Конфигурация считается базовой, если в ее имени есть термин "Базовая",
например, "УправлениеТорговлейБазовая".

Возвращаемое значение:
  Булево - Истина, если конфигурация - базовая.

### СтандартныеПодсистемыСервер.ЭтоУчебнаяПлатформа
```bsl
Функция ЭтоУчебнаяПлатформа() Экспорт
```
Возвращает признак того, что выполнение происходит на учебной платформе.
Используется, когда нужно поддержать работу кода, который зависит
от ограничений учебной версии платформы.

Возвращаемое значение:
  Булево - Истина, если выполнение происходит на учебной платформе.

Для использования в других библиотеках и конфигурациях.

### СтандартныеПодсистемыСервер.ИдентификаторИнформационнойБазы
```bsl
Функция ИдентификаторИнформационнойБазы() Экспорт
```
Получает уникальный идентификатор информационной базы,
с помощью которого можно различать различные экземпляры информационных баз,
например, при сборе статистики или в механизмах внешнего управления базами.
Если идентификатор не заполнен, то его значение автоматически устанавливается и возвращается.

Идентификатор хранится в константе ИдентификаторИнформационнойБазы.
Константа ИдентификаторИнформационнойБазы не должна входить в составы планов обмена, чтобы иметь
различные значения в каждой информационной базе (узле РИБ).

Возвращаемое значение:
 Строка - идентификатор информационной базы.

### СтандартныеПодсистемыСервер.ПрофильБезопасностиДляВыполнитьВычислить
```bsl
Функция ПрофильБезопасностиДляВыполнитьВычислить() Экспорт
```
Возвращает имя профиля безопасности информационной базы, который
нужно установить перед выполнением методов Выполнить, Вычислить
с сохранением текущего привилегированного режима (если установлен) и
с возможностью включения привилегированного режима в коде конфигурации, если потребуется.
Если в выполняемом коде привилегированный режим не требуется, тогда рекомендуется использовать
либо методы ОбщегоНазначения.ВыполнитьВБезопасномРежиме или ОбщегоНазначения.ВычислитьВБезопасномРежиме,
либо включение безопасного режима методом платформы УстановитьБезопасныйРежим(Истина).

Требуется для поддержки работы профилей безопасности (в КОРП-решениях).

Возвращаемое значение:
 Строка - если пустая, безопасный режим устанавливать не требуется.

Пример:

 Вариант 1. Внутри процедуры или функции.
...
ПрофильБезопасностиИБ = СтандартныеПодсистемыСервер.ПрофильБезопасностиДляВыполнитьВычислить();
Если ЗначениеЗаполнено(ПрофильБезопасностиИБ) Тогда
	УстановитьБезопасныйРежим(ПрофильБезопасностиИБ);
КонецЕсли;
Вычислить(...)
Если ЗначениеЗаполнено(ПрофильБезопасностиИБ) Тогда
	УстановитьБезопасныйРежим(Ложь);
КонецЕсли;
...

 Вариант 2. В конце процедуры или функции.
...
ПрофильБезопасностиИБ = СтандартныеПодсистемыСервер.ПрофильБезопасностиДляВыполнитьВычислить();
Если ЗначениеЗаполнено(ПрофильБезопасностиИБ) Тогда

Вычислить(...)

### СтандартныеПодсистемыСервер.ПараметрыАдминистрирования
```bsl
Функция ПараметрыАдминистрирования() Экспорт
```
Возвращает сохраненные в информационной базы параметры администрирования.
Предназначена для использования в механизмах, требующих для свой работы
ввода параметров администрирования информационной базы и/или кластера серверов.
Например, блокировка установки соединений с информационной базой.
См. так же УстановитьПараметрыАдминистрирования.

Возвращаемое значение:
 Структура - содержит свойства двух структур
             АдминистрированиеКластера.ПараметрыАдминистрированияКластера
             и АдминистрированиеКластера.ПараметрыАдминистрированияИнформационнойБазыКластера.
             При этом поля, содержащие пароли, возвращаются пустыми. Если параметры администрирования
             не были ранее сохранены при помощи функции УстановитьПараметрыАдминистрирования,
             то будут возвращены автоматически вычисленные параметры администрирования по умолчанию.

### СтандартныеПодсистемыСервер.УстановитьПараметрыАдминистрирования
```bsl
Процедура УстановитьПараметрыАдминистрирования(ПараметрыАдминистрированияИБ) Экспорт
```
Сохраняет параметры администрирования информационной базы и кластера серверов.
При сохранении поля, содержащие пароли, будут очищены в целях безопасности.

Параметры:
 ПараметрыАдминистрированияИБ - см. ПараметрыАдминистрирования

Пример:
 ПараметрыАдминистрирования = СтандартныеПодсистемыСервер.ПараметрыАдминистрирования();
 // Вывод параметров администрирования администратору для подтверждения корректности и ввода паролей.
 // Далее выполнение действий, связанных с подключением к кластеру серверов.
 СтандартныеПодсистемыСервер.ПараметрыАдминистрирования(ПараметрыАдминистрирования);

### СтандартныеПодсистемыСервер.ПереместитьЭлементыВГруппе
```bsl
Процедура ПереместитьЭлементыВГруппе(Группа, ОписаниеЭлементов) Экспорт
```
Позволяет скорректировать порядок одних элементов относительно других.
Кроме того, позволяет скрыть видимость элементов дублей в интерфейсе Такси, если созданы.

Параметры:
 Группа - ГруппаФормы
 ОписаниеЭлементов - Строка - многострочная строка со строками в следующих вариантах
     "ИмяПеремещаемогоЭлемента" - вставить после предыдущего (в первой строке вставить в начало),
     "ИмяПеремещаемогоЭлемента>ИмяЭлементаПередКоторымВставить" - вставить перед указанным элементом,
     "ИмяПеремещаемогоЭлемента>." - вставить в конец,
     "ИмяПеремещаемогоЭлемента<ИмяЭлементаПослеКоторогоВставить" - вставить после указанного элемента.
   Вместо "ИмяПеремещаемогоЭлемента" можно указать два имени через двоеточие
     "ИмяПеремещаемогоЭлемента:ЭлементКоторомуОтключитьВидимость", например,
     отключить видимость дубля элемента в интерфейсе Такси.
   Вместо "ИмяЭлементаПередКоторымВставить" или "ИмяЭлементаПослеКоторогоВставить"
     можно указать несколько имен через слеш, например,
     "ИмяЭлементаПередКоторымВставить1/ИмяЭлементаПередКоторымВставить2",
     тогда если первый элемент не найден, будет использоваться второй.
   Если имя элемента не найдено, то элемент пропускается (как будто не указан).

Пример:
СтандартныеПодсистемыСервер.ПереместитьЭлементыВГруппе(Элементы.Список.КоманднаяПанель,
	"СписокВключитьПометку
	|СписокОтключитьПометку
	|СписокВыбрать:ФормаВыбрать
	|ФормаИмпортФайлов>ФормаГлобальныеКоманды
	|ФормаИмпортПапки
	|СписокУстановитьПароль<СписокИзменить/СписокСкопировать
	|СписокНазначитьГруппы
	|ФормаИзменитьФорму>.
	|ФормаСправка"
Первый элемент СписокВключитьПометку без уточнения куда вставить и на первой строке,
	поэтому вставляется в начало.
Второй элемент СписокОтключитьПометку тоже без уточнения куда вставить, но не на первой строке,
	поэтому идет за предыдущим СписокВключитьПометку.
Третий элемент СписокВыбрать тоже без уточнения куда вставить,
	поэтому идет за предыдущим СписокОтключитьПометку,
	но у элемента ФормаВыбрать отключается видимость (если найден).
Четвертый элемент ФормаИмпортФайлов с уточнением вставить перед элементом ФормаГлобальныеКоманды,
	поэтому, если элемент ФормаГлобальныеКоманды будет найден,
	тогда элемент ФормаИмпортФайлов вставится перед ним,
	в противном случае вставится за предыдущим элементом СписокВыбрать.
Пятый элемент ФормаИмпортПапки без уточнения куда вставить,
	поэтому идет за предыдущим ФормаИмпортФайлов.
Шестой элемент СписокУстановитьПароль с уточнением вставить после элемента СписокИзменить,
	поэтому вставится после СписокИзменить, если элемент СписокИзменить будет найден,
	в противном случае вставится после СписокСкопировать, если элемент СписокСкопировать будет найден,
	в противном случае вставится за предыдущим элементом ФормаИмпортПапки.
Седьмой элемент СписокНазначитьГруппы без уточнения куда вставить,
	поэтому идет за предыдущим СписокУстановитьПароль.
Восьмой элемент ФормаИзменитьФорму с уточнением вставить в конец,
	поэтому будет перемещен в конец (без вариантов).
Девятый элемент ФормаСправка без уточнения куда вставить,
	поэтому идет за предыдущим ФормаИзменитьФорму.

### СтандартныеПодсистемыСервер.СкопироватьНедостающиеКнопки
```bsl
Процедура СкопироватьНедостающиеКнопки(Группа, ОписаниеЭлементов) Экспорт
```
Копирует в указанную группу недостающие элементы с указанными именами,
например, кнопки из командной панели в контекстное меню.

Параметры:
 Группа - ГруппаФормы
 ОписаниеЭлементов - Строка - многострочная строка формата
  "ИмяКопируемогоЭлемента*ИмяЭлементаКопии
  |..."

Пример:
СтандартныеПодсистемыСервер.СкопироватьНедостающиеКнопки(Элементы.ПользователиИБ.КонтекстноеМеню,
	"ПерейтиКПользователю*КонтекстноеМенюПерейтиКПользователю
	|Сопоставить*КонтекстноеМенюСопоставить
