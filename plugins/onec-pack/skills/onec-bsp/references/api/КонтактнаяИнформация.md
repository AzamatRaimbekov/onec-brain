### РаботаСАдресами.РегионАдресаКонтактнойИнформации
```bsl
Функция РегионАдресаКонтактнойИнформации(Знач Адрес) Экспорт
```
Возвращает официальное наименование субъекта РФ для адреса или пустую строку, если субъект не определен.
Если переданная строка не содержит информации об адресе, то будет вызвано исключение.

Параметры:
   Адрес - Строка - строка в формате JSON или XML соответствующая XDTO пакету Адрес.
         - Структура - адрес с разбивкой по полям.

Возвращаемое значение:
  Строка

### РаботаСАдресами.ГородАдресаКонтактнойИнформации
```bsl
Функция ГородАдресаКонтактнойИнформации(Знач Адрес) Экспорт
```
Возвращает строковое представление наименования города.
Для города федерального значения возвращается наименование самого города.

Если переданная строка не содержит корректной информации об адресе, то функция вызывает исключение.

Параметры:
  Адрес - Строка -  адрес в формате JSON или XML, соответствующий XDTO-пакету "Адрес".
        - Структура - адрес с разбивкой по полям.

Возвращаемое значение:
  Строка - наименование города (например, "г Москва", "г Сочи")
           или пустая строка, если город не определен.

Возвращает сведения о муниципальном адресе в виде отдельных полей адреса.
При отсутствии данных возвращается пустая строка.

 Адрес - Строка - Адрес в формате JSON
 ДополнительныеПараметры - см. НовыйДополнительныеПараметрыДеленийАдресов

Возвращаемое значение:
  Структура - сведения о муниципальном адресе:
   * Представление    - Строка - текстовое представление адреса по муниципальному делению.

   * Комментарий      - Строка - дополнительный комментарий к адресу.

                        Например, для адреса "г Москва, вн.тер.г. городской округ Троицк, г Троицк, ул 3-я Вишневая,
                        д. 1" это будет идентификатор улицы "3-я Вишневая".

     ** Наименование  - Строка - название района без типа ("Ленинский").
     ** Тип           - Строка - тип муниципального образования ("муниципальный район").

### РаботаСАдресами.НовыйДополнительныеПараметрыДеленийАдресов
```bsl
Функция НовыйДополнительныеПараметрыДеленийАдресов() Экспорт
```
Возвращает структуру с дополнительными параметрами формирования представлений делений адресов.


Возвращаемое значение:
  Структура:
    * ВариантНаписанияТипа - Строка -способ отображения типа адресного элемента:
         "Полный"            - полное написание (например, "город");
         "Сокращенный"       - сокращенное написание (например, "г.");
         "СокращенныйПоПриказуМинфина171н" - сокращенное написание, соответствующее
                                               требованиям приказа Минфина РФ № 171н
                                               для типов адресных элементов, домов, зданий и помещений;
         "" (пустая строка)  - по умолчанию, преобразование типа не выполняется.
    * ВключатьСтрануВПредставление  - Булево -
        если Истина, то в строковом представлении адреса будет указана страна;
        если Ложь, страна исключается из представления.
    * ВключатьИндексВПредставление - Булево -
        если Истина, то в строковом представлении адреса будет включен почтовый индекс;
        если Ложь, индекс не включается в представление.

### РаботаСАдресами.ПредставлениеАдресногоЭлемента
```bsl
Функция ПредставлениеАдресногоЭлемента(Наименование, Тип, ИмяУровня = "", ВариантНаписанияТипа = "") Экспорт
```
Возвращает представление адресного элемента по правилам ГАР.
Для региона при доступности адресного классификатора всегда возвращается официальное наименование.

Параметры:
 Наименование         - Строка - название адресного объекта ("Московская", "Ленинская", "Сосновское").
 Тип                  - Строка - тип адресного объекта ("область", "д.", "ш").
 ИмяУровня            - Строка - (необязательный) уровень адресного элемента ("Регион", "Город", Улица" и др.)
                                 Если не указан, то будет использован первый найденный вариант.
 ВариантНаписанияТипа - Строка - Определяет формат написания типа адресного элемента (кроме Региона). Варианты значений,
                                  Полный - полное написание (например, «область»);
                                  Сокращенный - сокращенное написание (например, «обл.»);
                                  СокращенныйПоПриказуМинфина171н - сокращенное написание , где типы адресных элементов,
                                                 типы домов, зданий и помещений соответствуют приказу Минфина РФ N 171н.
                                  "" - По умолчанию, пустая строка (преобразование не выполняется).

Возвращаемое значение:
 Строка - полное представление адресного элемента:
          "Московская область", "Ленинский муниципальный район", "Московская обл." (при сокращении).

Пример:
 Регион = ПредставлениеАдресногоЭлемента("Кабардино-Балкарская", "респ", Истина); // "Кабардино-Балкарская Республика"
 Район  = ПредставлениеАдресногоЭлемента("Ленинский", "муниципальный район");     // "муниципальный район Ленинский"
 Регион = ПредставлениеАдресногоЭлемента("Приморск", "г.");                       // "г. Приморск"
 Улица  = ПредставлениеАдресногоЭлемента("Сосновское", "ш",, "Полный");  // "шоссе Сосновское"

### РаботаСАдресами.ПредставлениеАдресногоЭлементаПоУровню
```bsl
Функция ПредставлениеАдресногоЭлементаПоУровню(Адрес, ИмяУровня, ТипАдреса, ВариантНаписанияТипа = "") Экспорт
```
Возвращает представление адресного элемента из адреса по указанному уровню и типу деления.
Для регионов автоматически возвращает официальное наименование из ГАР.

Параметры:
 Адрес                - Структура - адрес в формате JSON.
 ИмяУровня      - Строка - уровень адресного объекта по ГАР: "Регион", "МуниципальныйРайон", "Поселение",
                                           "Город", "НаселенныйПункт", "Территория", "Улица".
 ТипАдреса            - Строка - тип адресного деления:
                                 РаботаСАдресамиКлиентСервер.МуниципальныйАдрес() или
                                 РаботаСАдресамиКлиентСервер.АдминистративноТерриториальныйАдрес().
 ВариантНаписанияТипа - Строка - вариант сокращения типа адресного элемента или объекта:

Добавляет (удаляет) поле ввода или комментарий на форму, обновляя данные.

   Результат - Неопределено - служебный реквизит, полученный из предыдущего обработчика события.
             - Структура: - набор свойств динамический:
     * ПоменятьМестамиЭлементы - Булево - если значения элементов меняются местами.
     * ПервыйЭлемент - Строка - если значения элементов меняются местами.
     * ВторойЭлемент - Строка - если значения элементов меняются местами.
     * ОбновитьКонтекстноеМеню - Булево -  если выполняется обновление меню
     * ИмяРеквизита - Строка - если выполняется обновление меню
     * ДобавляемыйВид - Булево - при добавлении нового элемента
     * ЭтоДобавлениеКомментария - Булево - при добавлении комментария
     * ОбновитьКонтекстноеМеню - Булево - при обновлении контекстного меню
     * ИмяЭлементаДляРазмещения - Строка -  если добавляет новый элемент, комментарий или обновляется контекстное меню
     * Комментарий - Строка - при обновлении контекстного меню
      * Перечитать  - Булево - если нужно полностью обновить контактную информацию в рамках элемента для размещения.

Возвращаемое значение:
   Неопределено - значение не используется, обратная совместимость.

### УправлениеКонтактнойИнформацией.ПредставлениеАдреса

Возвращает форматированное представление адреса.

Функция формирует строковое представление адреса в соответствии
с указанным порядком полей. Поддерживает различные форматы вывода,
включая обратный порядок (от номера дома к региону) и сокращенные варианты.

  ПараметрыПредставленияАдреса - см. НовыеПараметрыПредставленияАдреса
                               - Неопределено - параметры по умолчанию.

### УправлениеКонтактнойИнформациейПереопределяемый.ПриОпределенииНастроек
```bsl
Процедура ПриОпределенииНастроек(Настройки) Экспорт
```
Изменяет, добавляет, удаляет стандартные команды контактной информации, отображаемые в справочниках и документах.

Параметры:
 Настройки - Структура:
   * ОписаниеКоманд - см. УправлениеКонтактнойИнформацией.ОписаниеКоманд
   * ШиринаПоляКомментарий - Число - Устарело. Значение игнорируется.
   * ОтображатьИконки - Булево - Устарело. Значение игнорируется.
   * ПоложениеКнопкиДобавить - ГоризонтальноеПоложениеЭлемента - Устарело. Значение игнорируется.

 Пример:
    Настройки.ШиринаПоляКомментарий = 10;

    Адрес = Перечисления.ТипыКонтактнойИнформации.Адрес;
    Настройки.ОписаниеКоманд[Адрес].ЗапланироватьВстречу.Заголовок  = НСтр("ru='Встреча'");
    Настройки.ОписаниеКоманд[Адрес].ЗапланироватьВстречу.Подсказка  = НСтр("ru='Создать событие встречи'");
    Настройки.ОписаниеКоманд[Адрес].ЗапланироватьВстречу.Картинка   = БиблиотекаКартинок.ЗапланированноеВзаимодействие;
    Настройки.ОписаниеКоманд[Адрес].ЗапланироватьВстречу.Действие   = "СтандартныеПодсистемыКлиент.ОткрытьФормуДокументаВстреча";

    ФактическийАдресОрганизации = УправлениеКонтактнойИнформацией.ВидКонтактнойИнформацииПоИмени("ФактическийАдресОрганизации");
     Настройки.ОписаниеКоманд[ФактическийАдресОрганизации] =
   	ОбщегоНазначения.СкопироватьРекурсивно(УправлениеКонтактнойИнформацией.КомандыТипаКонтактнойИнформации(Перечисления.ТипыКонтактнойИнформации.Адрес));
     Настройки.ОписаниеКоманд[ФактическийАдресОрганизации].ЗапланироватьВстречу.Действие = ""; // Отключение действия команды для вида

  Процедурам, указанных в свойстве Действие, передаются 2 параметра:
      КонтактнаяИнформация - Структура:
        * Представление - Строка
        * Значение      - Строка
        * Тип           - ПеречислениеСсылка.ТипыКонтактнойИнформации
        * Вид           - СправочникСсылка.ВидыКонтактнойИнформации
      ДополнительныеПараметры - Структура:
        * ВладелецКонтактнойИнформации - ОпределяемыйТип.ВладелецКонтактнойИнформации.
        * Форма - ФормаКлиентскогоПриложения - форма объекта-владельца, предназначенная для вывода контактной информации.

    Процедура ОткрытьФормуДокументаВстреча(КонтактнаяИнформация, ДополнительныеПараметры) Экспорт

	  Если ТипЗнч(ДополнительныеПараметры.ВладелецКонтактнойИнформации) = Тип("ДокументСсылка.ЗаказПокупателя") Тогда
	    	ЗначенияЗаполнения.Вставить("Предмет", ДополнительныеПараметры.ВладелецКонтактнойИнформации);
	    	ЗначенияЗаполнения.Вставить("Контакт", "");
	  Иначе
	    	ЗначенияЗаполнения.Вставить("Контакт", ДополнительныеПараметры.ВладелецКонтактнойИнформации);
	    	ЗначенияЗаполнения.Вставить("Предмет", "");
	  КонецЕсли;
