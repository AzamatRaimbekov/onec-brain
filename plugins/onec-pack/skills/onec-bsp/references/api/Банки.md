## РаботаСБанкамиКлиент
Модуль: Клиент

### РаботаСБанкамиКлиент.ВыбратьИзСправочникаБИК
```bsl
Процедура ВыбратьИзСправочникаБИК(БИК, Форма, ОбработчикОповещения = Неопределено) Экспорт
```
Открывает форму выбора Справочника БИК с отбором по переданному БИК.
Если в списке выбора единственная запись, то выбор в форме осуществляется автоматически.

Параметры:
 БИК - Строка - банковский идентификационный код.
 Форма - ФормаКлиентскогоПриложения - форма, из которой открывается форма выбора.
 ОбработчикОповещения - ОписаниеОповещения - процедура, в которую передается управление после осуществления выбора.
                                             Если параметр не указан, то будет вызван стандартный обработчик выбора.
   Параметры процедуры:
    * БИК - СправочникСсылка.КлассификаторБанков - выбранный элемент.
    * ДополнительныеПараметры - Произвольный - параметр, переданный в конструкторе описания оповещения.

## РаботаСБанкамиПереопределяемый
Модуль: Сервер, ВнешнееСоединение · переопределяемый: заполняется в конфигурации

### РаботаСБанкамиПереопределяемый.ПриОпределенииНеобходимостиПоказаПредупрежденияОбУстаревшемКлассификатореБанков
```bsl
Процедура ПриОпределенииНеобходимостиПоказаПредупрежденияОбУстаревшемКлассификатореБанков(ПоказыватьПредупреждение) Экспорт
```
Включает/отключает показ предупреждений о необходимости обновления классификатора банков.

Параметры:
 ПоказыватьПредупреждение - Булево - при установке значения Ложь предупреждения показываться не будут.

### РаботаСБанкамиПереопределяемый.ПриОпределенииНастроекЗагрузкиКлассификатораБанков
```bsl
Процедура ПриОпределенииНастроекЗагрузкиКлассификатораБанков(Настройки) Экспорт
```
Определяет настройки загрузки классификатора банков.

Параметры:
 Настройки - Структура:
  * ОбрабатыватьОбластиДанных - Булево - включает выполнение процедуры ПриОбработкеОбластиДанных при обновлении
                                         классификатора.

### РаботаСБанкамиПереопределяемый.ПриОбработкеОбластиДанных
```bsl
Процедура ПриОбработкеОбластиДанных() Экспорт
```
Используется только в разделенном режиме. Вызывается после загрузки классификатора для выполнения дополнительных
действий в областях данных. Выполнение процедуры необходимо включить в ПриОпределенииНастроек, по умолчанию выключена.
