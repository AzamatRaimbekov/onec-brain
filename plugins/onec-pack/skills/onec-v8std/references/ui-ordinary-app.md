# Интерфейсы обычного приложения (legacy) - стандарты 1С (v8std)

> Пересказ разделов «Разработка пользовательских интерфейсов (обычное приложение)», «Реализация работы формы»,
> «Организация диалога с пользователем» системы стандартов its.1c.ru/db/v8std, снят 2026-10-07. Это не копия: при
> сомнении открыть первоисточник по ссылке. Нумерация stdNNN совпадает с сайтом.

**Применять ТОЛЬКО к конфигурациям/формам обычного приложения (толстый клиент, обычные формы).** Для управляемых форм
и «Такси» эти правила не действуют - см. `ui-forms.md`, `ui-design-1.md`, `ui-design-2.md`. Все документы - стандарты
с областью «обычное приложение».

Оглавление: std500 общие правила, std501 общие интерфейсы, std502 интерфейс «Полный», std524 стили; std503 имя
элемента, std504 размер колонки, std505 размеры формы, std506 подсказки, std507 автовыбор незаполненного, std508
гиперссылки, std509 привязки, std510 отступы, std511 закладки, std512 порядок обхода, std513 кнопка справки, std514
единственное табличное поле, std515 разделители, std516 кнопки, std517 картинки, std518 видимость страниц, std519
программное управление формой, std520 условно доступные действия, std521 специализированные формы, std522 частые
события, std523 ТекущаяСтрока, std526 одинаковые тексты, std527 пояснения в полях, std528 второстепенные пункты меню;
std417 вопрос при закрытии

## Интерфейсы конфигурации

### std500 Общие правила построения интерфейсов - [its](https://its.1c.ru/db/v8std/content/500/hdoc)
- Отдельный интерфейс (главное меню + панели) на каждую крупную группу пользователей; обязательны интерфейсы «Общий»
  и «Полный».
- Главное меню дает доступ ко всем нужным формам; группы в подменю разделять, не более 7 пунктов в группе; меню
  помещается на экран при минимальном целевом разрешении; пункты объектов открывают формы списков.
- Доступно нужное, недоступно запрещенное; частое - ближе; однотипные блоки в разных интерфейсах - одинаково.

### std501 Общие интерфейсы - [its](https://its.1c.ru/db/v8std/content/501/hdoc)
- «Общий»: не переключаемый, подсистема - вся конфигурация. Верхний уровень: «Файл» крайним слева; «Сервис», «Окна»,
  «Справка» крайними справа. В «Сервис» можно «Переключить интерфейс» со всеми переключаемыми интерфейсами.
- «Операции» в «Общем» отключать, если не используется во всех переключаемых. Ролевые непереключаемые интерфейсы -
  с именами «Общий...», права по ролям.

### std502 Интерфейс "Полный" - [its](https://its.1c.ru/db/v8std/content/502/hdoc)
- Доступ ко всем действиям; верхний уровень - по функциональным группам (Зарплата, Бухгалтерия); «Операции»
  обязательно, если нет в «Общем»; запрещено группировать по видам объектов (Справочники, Документы, Отчеты).

### std524 Стили - [its](https://its.1c.ru/db/v8std/content/524/hdoc)
- Основной стиль конфигурации - «Основной», у форм - «Авто». Свои элементы стиля: `ТекстИнформационнойНадписи`,
  `ТекстПредупреждающейНадписи`, `ТекстВторостепеннойНадписи`, `ЦветГиперссылки` (цвета), `ШрифтВажнойНадписи` (шрифт).

## Реализация работы формы

### std503 Имя элемента управления - [its](https://its.1c.ru/db/v8std/content/503/hdoc)
- Имя = данные элемента (или данные флажка); путь через точку - без точек; без данных - тип элемента + назначение
  (`ПолеВыбораУсловияОтбора`); дубли - суффиксы 1, 2, 3 (`Номер1`, `НадписьНомер1`).

### std504 Изменения размера колонки табличного поля - [its](https://its.1c.ru/db/v8std/content/504/hdoc)
- `ИзменениеРазмераКолонки` разрешать при неизвестной/длинной ширине данных (ссылки, длинные строки); запрещать для дат,
  чисел, булевых; у колонки с иерархией - всегда разрешать.

### std505 Размеры формы - [its](https://its.1c.ru/db/v8std/content/505/hdoc)
- Расчет: 1280x768, окно на весь экран, главное меню, одна строка панелей, панель окон и состояния. Максимум формы
  1256x580; с закладками - ширина, при которой видны все заголовки закладок.

### std506 Подсказки - [its](https://its.1c.ru/db/v8std/content/506/hdoc)
- Подсказка у элемента обязательна, не длиннее 8 слов.

### std507 Использование флагов "Автовыбор незаполненного" и "Автоотметка незаполненного" - [its](https://its.1c.ru/db/v8std/content/507/hdoc)
- При «Автоотметке незаполненного» ставить и «Автовыбор незаполненного» с режимом «При нажатии Enter» (и в колонках
  табличных полей); для чисел и дат - по логике.

### std508 Использование гиперссылок в диалогах форм - [its](https://its.1c.ru/db/v8std/content/508/hdoc)
- Кнопки - изменение данных формы/ИБ (особенно необратимое), выбор, подбор, заполнение. Гиперссылки - переход к другой
  немодальной форме или странице.

### std509 Привязки - [its](https://its.1c.ru/db/v8std/content/509/hdoc)
- Ручных привязок минимум. По горизонтали не растягиваются надписи (кроме информационных и гиперссылок), флажки,
  переключатели, кнопки, поля фиксированной длины; остальные (поля, таблицы, панели, документы, диаграммы...) -
  растягиваются: один в строке - с формой, несколько - пропорционально, граница левой колонки - пропорционально.
- По вертикали растягиваются только многострочные поля, таблицы, списки, панели, рамки, поля документов, диаграммы,
  картинки; один в столбце - с формой, несколько - пропорционально.
- Разделитель: элементы по сторонам привязываются к нему как к краю формы (так же внутри панелей).

### std510 Отступы - [its](https://its.1c.ru/db/v8std/content/510/hdoc)
- Форма: 8 со всех сторон (сверху/снизу 33 при командной панели). Панель: 6 со всех сторон.

### std511 Использование закладок - [its](https://its.1c.ru/db/v8std/content/511/hdoc)
- Запрещены страницы у самой формы. У панели не более 5 видимых закладок сверху; больше или слева - только для форм
  настроек и программно генерируемых страниц.

### std512 Порядок обхода элементов диалога - [its](https://its.1c.ru/db/v8std/content/512/hdoc)
- «Автопорядок обхода» всегда, кроме случаев нарушения логики; сверху вниз, слева направо; старт - «Активизировать по
  умолчанию»; группы (переключатели, флажки, рамки) обходятся целиком как один элемент.

### std513 Размещение кнопки вызова справки в формах - [its](https://its.1c.ru/db/v8std/content/513/hdoc)
- В верхней командной панели (или основной), при выравнивании «Лево» - крайней правой; допустимо отдельно в форме.

### std514 Отображение единственного табличного поля в форме - [its](https://its.1c.ru/db/v8std/content/514/hdoc)
- Над командной панелью единственного табличного поля - рамка группы «Подчеркивание» с осмысленным названием данных.

### std515 Разделители - [its](https://its.1c.ru/db/v8std/content/515/hdoc)
- Вертикальные - ширина 6, горизонтальные - высота 6, привязка поперек - «НеПривязано», рамка «НетРамки» («Одинарная» -
  если иначе не догадаться); соседние элементы вплотную к разделителю.

### std516 Кнопки - [its](https://its.1c.ru/db/v8std/content/516/hdoc)
- Кнопки вне командных панелей: минимум 60x19, надпись в одну строку; частотные - текст + картинка.

### std517 Картинки - [its](https://its.1c.ru/db/v8std/content/517/hdoc)
- Только стандартные и конфигурационные картинки (не из файлов); для стандартных действий - стандартные картинки.
  Кнопки выбора в поле - 9x15; кнопки и командные панели - 16x16, `РазмерКартинки` = `РеальныйРазмер`.

### std518 Программное управление видимостью страниц - [its](https://its.1c.ru/db/v8std/content/518/hdoc)
- Всегда должна быть видна хотя бы одна страница: сначала включать нужные, потом выключать лишние (иначе ломаются
  привязки).

### std519 Программное управление формой - [its](https://its.1c.ru/db/v8std/content/519/hdoc)
- В модуле формы обращаться к ее свойствам/методам напрямую, без `ЭтаФорма` (кроме неизбежных случаев).
- В разделе инициализации модуля формы не открывать формы и диалоги (`Вопрос`, `Предупреждение`).
- Извне - только через реквизиты/свойства и экспортные методы формы; не обращаться к `ЭлементыФормы` чужой формы и не
  строить предположений о внутреннем устройстве реквизитов.

### std520 Ограничение выполнения действий, доступных только при определенных условиях - [its](https://its.1c.ru/db/v8std/content/520/hdoc)
- Условно допустимую кнопку не блокировать: проверять условие в обработчике и кратко объяснять причину отказа.

### std521 Поведение специализированных форм - [its](https://its.1c.ru/db/v8std/content/521/hdoc)
- Форма, рассчитанная на особый контекст, при открытии вне его закрывается с диагностическим сообщением (откуда ее
  вызывать).

### std522 Обращение к данным информационной базы в обработчиках часто вызываемых событий - [its](https://its.1c.ru/db/v8std/content/522/hdoc)
- Минимизировать обращения к ИБ в `ОбновлениеОтображения`, `ПриВыводеСтроки`, `ПриАктивацииСтроки`: кэш в переменных
  модуля, перенос в другие события, подготовка данных при заполнении таблиц значений.

### std523 Обращение к свойству "ТекущаяСтрока" табличного поля - [its](https://its.1c.ru/db/v8std/content/523/hdoc)
- Запрещено читать поля строки через `ТекущаяСтрока`; использовать `ТекущиеДанные` или `ДанныеСтроки`.
- В динамических списках нужные невидимые колонки явно добавлять в `Колонки` источника до открытия формы (системные
  поля - `ПометкаУдаления`, `ЭтоГруппа`, `Дата` - доступны всегда).

### std526 Ограничения по использованию одинаковых текстов на элементах управление в форме - [its](https://its.1c.ru/db/v8std/content/526/hdoc)
- Не размещать элементы одного типа с одинаковым текстом (несколько подменю «Действия»).

### std527 Использование пояснений в полях ввода и выбора - [its](https://its.1c.ru/db/v8std/content/527/hdoc)
- В пустом поле показывать значение по умолчанию или смысл пустого значения.

### std528 Особенности размещения в командных панелях пунктов меню, не предназначенные для решения основных задач - [its](https://its.1c.ru/db/v8std/content/528/hdoc)
- Специализированные пункты для узких групп - в подменю.

## Диалог с пользователем

### std417 Вопрос при закрытии программы - [its](https://its.1c.ru/db/v8std/content/417/hdoc)
- При выходе спрашивать «Завершить работу с программой?»; отказ - продолжить работу; вопрос отключается в персональных
  настройках.
