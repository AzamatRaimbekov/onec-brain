## Оформление форм списков

### std581 Быстрые отборы в списках - [its](https://its.1c.ru/db/v8std/content/581/hdoc)
- Делать, если список частый с типовыми «запросами» (контрагент, период), объектов много или выбор/поиск - частая операция.
- Поля/флажки - перед списком (сверху, слева, справа); полезный, но редкий отбор можно вниз. Верхние - над командной
  панелью списка.
- Необязательные отборы - с кнопкой очистки (или одна кнопка очистки всех); без кнопки открытия; при чрезмерном
  растягивании - фиксированная ширина.

### std582 Команда "Создать" в журналах документов - [its](https://its.1c.ru/db/v8std/content/582/hdoc)
- Подменю «Создать» с конкретными видами документов - для частых журналов с небольшим числом видов (до 6).
- Картинка только у подменю; команды по частоте, не по алфавиту; `Insert` по-прежнему открывает выбор типа документа.

### std584 Акцентирование внимания на просроченных или критичных состояниях - [its](https://its.1c.ru/db/v8std/content/584/hdoc)
- Выделять только ячейки, объясняющие причину (статус и срок), цветом текста `ПросроченныеДанные` (178,34,34).

### std604 Многоэтажные списки - [its](https://its.1c.ru/db/v8std/content/604/hdoc)
- Применять, когда важно видеть без прокрутки, колонок много (более 10) или иначе нужна горизонтальная прокрутка;
  помнить, что визуальный поиск в них хуже.

### std606 Команды, размещаемые во "Всех действиях" - [its](https://its.1c.ru/db/v8std/content/606/hdoc)
- По умолчанию - умолчание платформы; при ручной настройке на панели не более 10 частых команд, остальное - в «Все
  действия».

### std607 Заголовки списков - [its](https://its.1c.ru/db/v8std/content/607/hdoc)
- Список с командной панелью - заголовок группой с рамкой «линия»; без панели - заголовок в положении «верх».
- Количество элементов - только если помогает задаче, единообразно во всех аналогичных формах, в скобках после
  заголовка, у пустого списка не показывать.
- Без заголовка: единственный список на форме, два связанных очевидных списка, список на отдельной вкладке. В
  остальных случаях заголовок нужен.

### std609 Группировки в списках - [its](https://its.1c.ru/db/v8std/content/609/hdoc)
- Только если реально облегчает визуальный поиск; варианты группировок можно вынести в быстрые отборы; помнить о
  производительности (std489).

### std610 Пояснение невозможности заполнения ячеек в табличных частях - [its](https://its.1c.ru/db/v8std/content/610/hdoc)
- Ненужную в текущем состоянии ячейку пояснять текстом в угловых скобках, с маленькой буквы, цветом
  `ТекстЗапрещеннойЯчейки` (192,192,192): `<характеристики не используются>`.

### std616 Формы списков - [its](https://its.1c.ru/db/v8std/content/616/hdoc)
- Состав и порядок колонок - по сценарию заполнения; этажи вместо горизонтальной прокрутки; фиксировать «№»,
  «Номенклатура» и т.п.
- В динамические списки (не ТЧ) можно добавлять колонки «с запасом», скрытые по умолчанию.
- Активная колонка по умолчанию - самая вероятная для поиска; не использовать режим выделения «строка».

### std617 Списки с одной колонкой - [its](https://its.1c.ru/db/v8std/content/617/hdoc)
- Без шапки, без горизонтальной разлиновки и чередования строк; учитывать сходство с многострочным полем.

### std618 Размеры списков - [its](https://its.1c.ru/db/v8std/content/618/hdoc)
- Высота - по типовому числу строк из практики (документов-заказов 3-5 мало, больше 20 много); одинаковая высота не
  обязательна. Высота строки при обычном шрифте 19 pt; одинарная для коротких значений, двойная - для длинных.
- Ширина колонки ≈ число символов / 1,25. Ориентиры (символы → ширина): Банк, Банковский счет, Комментарий,
  Контрагент, Номенклатура, Организация, Подразделение, Описание 20→16; Договор 24→19; Дата со временем 19→13;
  БИК, КПП 9→7; Валюта 3→3; Год 4→4; Код ИФНС 4→4; Индекс 6→5; ИНН ФЛ 12→10; ИНН ЮЛ 10→8; Месяц 8→7; Номер 11→9;
  Номер ГТД 30→23; ОГРН 13→10; ОКАТО 11→9; Ответственный 15→12.

### std627 Колонки с флажками - [its](https://its.1c.ru/db/v8std/content/627/hdoc)
- Короткие заголовки; лучше картинка с подсказкой или сокращение (но много картинок замедляет открытие).

### std653 Групповые обработки в списках - [its](https://its.1c.ru/db/v8std/content/653/hdoc)
- Сообщать, у скольких объектов операция выполнена успешно; при частичных/полных неудачах обязательно сообщать (в т.ч.
  «изменение не требуется»).
- При группировке списка строки группировок в выделении игнорировать; если выделена только группировка - выдать
  сообщение о невозможности (см. std495).

## Формы

### std587 Поля "Ответственный" и "Комментарий" - [its](https://its.1c.ru/db/v8std/content/587/hdoc)
См. 8.3 std719 (приоритет)
- Группа в самом низу формы. «Ответственный» не на всю ширину, по типичным значениям.
- «Комментарий»: заголовок слева, на всю ширину, не растягивается по вертикали. Многострочный (`МногострочныйРежим` =
  Да) - высота 2 строки, кнопка выбора открывает блокирующий редактор; однострочный (Авто) - 1 строка без кнопки.
  Большой - на вкладку «Комментарий» (как в std719).

### std588 Группа полей "Наименование", "Код", "Полное наименование", "Входит в группу" - [its](https://its.1c.ru/db/v8std/content/588/hdoc)
- Вверху формы: «Наименование» и за ним «Код» в одну строку, ниже «Полное наименование», последним «Входит в группу»
  (так и озаглавить). Заголовки остальных - по синонимам. «Код» пропускать при вводе с клавиатуры.

### std589 Выбор: блокирующая форма или независимая - [its](https://its.1c.ru/db/v8std/content/589/hdoc)
- Блокирующая: работа «за один заход», элементов мало (менее 5). Независимая: нужны другие формы, сравнение объектов,
  элементов больше 9. См. std742.

### std597 Компоновка форм - [its](https://its.1c.ru/db/v8std/content/597/hdoc)
См. 8.3 std722
- Один реквизит - одно место во всех формах. В шапке документа - только реквизиты регистрации; содержательные, итоговые,
  второстепенные - не в шапке. Шапка в 1-3 колонки.
- Левая колонка: Номер/дата, Вид операции, Контрагент, его банковский счет, Договор, Контактное лицо. Правая:
  Организация, ее банковский счет, Подразделение, Склад, Касса, Регистрация в ИФНС.
- Зависимые поля - одно под другим (Подразделение под Организацией); зависящие от «Вида операции» - под ним.

### std611 Панель навигации вспомогательного окна - [its](https://its.1c.ru/db/v8std/content/611/hdoc)
- Связанные списки/отчеты/доп. сведения объекта - командами ПН формы, а не вкладками в форме (единообразие, скорость).
- Для важных форм вручную отбирать видимые команды; не более 10.
- Не размещать в ПН переходы к формам редактирования реквизитов объекта; открывать форму элемента из ПН другой формы
  элемента недопустимо.

### std612 Формы выбора - [its](https://its.1c.ru/db/v8std/content/612/hdoc)
- По умолчанию - автогенерируемые. Свою - только при особом составе команд/колонок: минимум команд (выбрать, создать,
  найти/отобрать), быстрый отбор для частых больших списков, колонки под визуальный поиск.

### std619 Формы - [its](https://its.1c.ru/db/v8std/content/619/hdoc)
- Оптимизировать под клавиатуру: логичный обход по Tab, связанные поля подряд, последний переход - на завершающую кнопку.

### std620 Командная панель формы - [its](https://its.1c.ru/db/v8std/content/620/hdoc)
- Кнопка по умолчанию - первая слева (см. 8.3 std716).

### std621 Группы элементов формы - [its](https://its.1c.ru/db/v8std/content/621/hdoc)
- Группировать элементы с общим признаком; групп из одного элемента не делать; 4-9 элементов, больше 9 - делить.
- Заголовок группы - когда нужен для пояснения; не нужен для единственной группы на вкладке.

### std634 Взаимосвязанные поля - [its](https://its.1c.ru/db/v8std/content/634/hdoc)
- Зависимое поле («Договор», «Подразделение») недоступно, пока не заполнено основное («Контрагент», «Организация»).

### std681 Размеры - [its](https://its.1c.ru/db/v8std/content/681/hdoc)
- Размеры формы/элементов задавать только в особых случаях (декорации), иначе умолчание. Ширина форм со страницами -
  чтобы все закладки были видны. Ширину колонок формы менять только для простых масштабируемых наборов; для форм
  объектов - авто.

### std682 Порядок полей - [its](https://its.1c.ru/db/v8std/content/682/hdoc)
- Кнопкам ставить `ПропускатьПриВводе`; стартовому полю ввода - `АктивизироватьПоУмолчанию`.

### std684 Список, открываемый из панели навигации формы объекта - [its](https://its.1c.ru/db/v8std/content/684/hdoc)
- Список с отбором по объекту; не выводить название объекта ни надписью, ни колонкой; в названии команды ПН объект не
  упоминать («Договоры», а не «Договоры контрагента»).

### std695 Командные панели табличных частей - [its](https://its.1c.ru/db/v8std/content/695/hdoc)
Только ТЧ форм объектов, не формы списков
- Команды заполнения строк работают по выделенным строкам (одна «Заполнить по виду цен», а не две версии); при этом
  добавить «Выделить все» в «Все действия».
- Команды по строкам, отобранным алгоритмом, - только для частых операций, где выделить вручную сложно.
- Если рядом есть схожие команды «по выделенным» и «по всем» - это должно быть ясно из названий.

### std696 Формы пошаговых помощников (мастеров) - [its](https://its.1c.ru/db/v8std/content/696/hdoc)
- Командная панель внизу формы; на каждом шаге одна кнопка по умолчанию (желтый фон, жирный).
- Кнопки: «Назад <» (крайняя левая, нет на первом шаге), «Далее >», подтверждающая - глагол действия или «Готово» (не
  «ОК»; «>» только на промежуточном шаге), «Закрыть» (по умолчанию на экране результатов), «Отмена» (между
  подтверждающей и «Справкой»; при введенных данных спросить о сохранении), «Справка» (крайняя правая, только если есть
  справка).

## Оформление элементов

### std590 Частотные кнопки - [its](https://its.1c.ru/db/v8std/content/590/hdoc)
- Частые кнопки - текст + картинка (картинку можно повторить в строке ТЧ); команды для узких групп - в подменю.

### std591 Команда «Подобрать» - [its](https://its.1c.ru/db/v8std/content/591/hdoc)
- Название «Подобрать» (инфинитив); первой, если удобнее «Добавить», иначе второй; клавиша `F8`.

### std592 Команда «Отмена» - [its](https://its.1c.ru/db/v8std/content/592/hdoc)
- «Отмена» реально отменяет и закрывает форму; не бывает кнопкой по умолчанию - если кроме закрытия ничего нет, то
  кнопка «Закрыть».

### std593 Единицы измерения - [its](https://its.1c.ru/db/v8std/content/593/hdoc)
- Поля: единица после поля, не в заголовке, без скобок; расшифровка единицы - в скобках после нее.
- Списки: колонка «Ед. изм.» (для денег - «Валюта»); одинаковая единица - в заголовке колонки («Сумма, руб.»);
  разная - сразу после значения (отдельной колонкой или в ячейке); общая для нескольких колонок - перед ними.

### std594 Значения по умолчанию - [its](https://its.1c.ru/db/v8std/content/594/hdoc)
- Термин «основной». В списке - команда «Использовать как основной/основную/основное» (род по заголовку формы),
  основной элемент шрифтом `ОсновнойЭлементСписка` (жирный).
- В форме: одно такое поле - «(основной)» после заголовка; несколько - группа «Используются как основные».
- При заполнении умолчаний в форме с подчиненными формами - записывать автоматически, без вопросов.

### std595 Гиперссылка на счет-фактуру - [its](https://its.1c.ru/db/v8std/content/595/hdoc)
- Внизу формы перед «Ответственный/Комментарий», отдельной строкой слева, с подписью «Счет-фактура» (можно с уточнением
  типа), на всю ширину (или колонки); несколько - друг под другом.
- Текст: «Создать счет-фактуру» / номер и дата / «Не требуется». Для создания записывать текущий объект автоматически,
  без вопроса. Нет права создания при праве чтения - надпись `<Недостаточно прав для создания счета-фактуры>` цветом
  `ПояснениеОтсутствующейГиперссылки`.

### std599 Выбор: кнопка или гиперссылка - [its](https://its.1c.ru/db/v8std/content/599/hdoc)
- Кнопка: самостоятельная операция, изменение данных; необратимые изменения (очистка ТЧ) - всегда кнопка; название -
  глагол («Заполнить», «Рассчитать»); рядом с объектом воздействия.
- Гиперссылка: переход к связанным данным/форме; из текста ясно, что откроется.

### std602 Переход к форме с дополнительными реквизитами - [its](https://its.1c.ru/db/v8std/content/602/hdoc)
См. 8.3 std722
- Гиперссылка с подписью-заголовком открываемой формы. В тексте - частые, влияющие и обязательные реквизиты через
  «; », «Заголовок: значение» (можно без заголовка, если ясно); пустое - `<Тип цен: не указан>`; флажок - «Цена
  включает НДС» / «Цена не включает НДС».

### std613 Итоги в документах - [its](https://its.1c.ru/db/v8std/content/613/hdoc)
См. 8.3 std718
- В подвале колонок - если нет горизонтальной прокрутки и итог явно привязан к колонке; иначе - область итогов внизу,
  только итоговые элементы (счет-фактура - до нее, Ответственный/Комментарий - после).
- Группы с рамкой и заголовком (надписи) - при 3+ показателях и без копирования; отдельные поля ввода (только чтение,
  справа, без слова «итог», валюта после поля) - при 1-2 показателях или нужном копировании.
- Обновлять итоги при каждом изменении содержимого, не только при записи; подсказка, откуда цифра. Цвета:
  `ИтоговыеПоказателиДокументов` (22,39,121) для нейтральных, `ПросроченныеДанные` для негативных; главное значение -
  шрифт `ОсновноеИтоговоеЗначение`. Связанные поля («Всего», «НДС») - в одной строке, сравниваемые - друг под другом.

### std614 Итоги в журналах документов - [its](https://its.1c.ru/db/v8std/content/614/hdoc)
- Внизу слева, надписями; цвет `ИтогиЖурналаЦвет` (100,100,100), шрифт `ИтогиЖурналаШрифт` (жирный).

### doc622 Флажки - [its](https://its.1c.ru/db/v8std/content/622/hdoc)
- Подпись справа от флажка, с заглавной буквы, одно короткое предложение, без отрицания (умолчание «включено» - через
  «Значение заполнения» = Истина у реквизита). Отрицание - только где естественно («Больше не спрашивать»,
  «Недействительный»).
- Подсказка - снизу или справа от подписи. Второй вариант должен быть очевиден; если нет - радиокнопки с явными
  вариантами. Общий текст группы флажков - в заголовок группы.

### std624 Оформление элементов - [its](https://its.1c.ru/db/v8std/content/624/hdoc)
- Одинаковые объекты (номер, дата, контрагент, соглашение) - одинаково названы и расположены во всех формах.

### std625 Картинки (иконки) в названии команд - [its](https://its.1c.ru/db/v8std/content/625/hdoc)
- Иконка - если функция однозначно читается или команду надо выделить; единственная команда панели - обязательно с
  картинкой. Только картинка - для стандартных (сохранить, удалить, скопировать...) и частых функций; без невнятных
  метафор.

### std631 Поле, влияющее на состав остальных полей в форме - [its](https://its.1c.ru/db/v8std/content/631/hdoc)
- «Вид операции» и т.п. выделять фоном `ФонУправляющегоПоля` (255,232,179).

### std635 Невыбранная картинка - [its](https://its.1c.ru/db/v8std/content/635/hdoc)
- Пустое поле картинки - с текстом («Добавить фото») цветом `ТекстНевыбраннойКартинкиЦвет` и шрифтом
  `ТекстНевыбраннойКартинкиШрифт` (12).

### std649 Реквизиты - [its](https://its.1c.ru/db/v8std/content/649/hdoc)
- Не убирать стандартные поля (наименование, номер, дата); единственный вариант выбора подставлять по умолчанию
  (одна ставка НДС, один договор); при вводе на основании заполнять все наследуемые реквизиты.

### doc694 Подменю - [its](https://its.1c.ru/db/v8std/content/694/hdoc)
- Однотипные команды - в подменю; общий текст их заголовков - в заголовок подменю; подменю из одной команды не делать.

## Отчеты

### std670 Содержание отчета - [its](https://its.1c.ru/db/v8std/content/670/hdoc)
- Только показатели одной цели анализа; в отчетах без СКД - расшифровка всех показателей; помеченные на удаление не
  выводить (или явно выделять, std676).
- Валюта показателя единая в отчете; при анализе в разных валютах - и исходная, и приведенная.
- Контекстный отчет (из ПН объекта, с автоотбором) vs неконтекстный (из КИ). Контекстные варианты не показывать в
  выборе вариантов/панели отчетов; объект-контекст исключать из группировок; в СКД имя контекстного варианта содержит
  «Контекст».

### std671 Варианты отчетов - [its](https://its.1c.ru/db/v8std/content/671/hdoc)
- Варианты - один источник данных в разных группировках/сортировках/отборах/наборах показателей. Вариант-рабочее место
  или очень частый - отдельный отчет.
- Для разных подсистем раздела - отдельные варианты с отборами, а не один вариант в нескольких подсистемах.
- С БСП описание варианта (назначение, состав данных) - обязательно.

### std672 Поля периодов - [its](https://its.1c.ru/db/v8std/content/672/hdoc)
- Пути `Периоды.Год`...`Периоды.Секунда`, синонимы «Период, год», «Период, месяц» и т.д.
- Форматы (Л=ru): год `yyyy "г."`; полугодие `ММ.гггг "г."`; квартал `к "квартал" гггг "г."`; месяц
  `MMMM гггг "г."`; декада/неделя/день `dd.MM.yyyy "г."`.
- `ПериодСекунда` - запрет как поля выбора/отбора/группировки/порядка; `Регистратор` - представление «Регистратор»,
  упорядочивание `ПериодСекунда возр, Регистратор возр`.

### std673 Пользовательские настройки - [its](https://its.1c.ru/db/v8std/content/673/hdoc)
- Понятные названия («Оплатить позже», а не «Дата оплаты Меньше или равно»). Без обязательного параметра запрос
  бессмысленен - «Запрещать незаполненные значения» + режим «Всегда»; заполнять вероятным значением («Этот месяц»).
- Быстрых настроек 5-7: все параметры отчета и отборы по важным группировкам; переключатели элементов (диаграмма/
  список); в контекстных - без отборов, заданных командой вызова.
- Обычные (режим «Обычный»): отборы по невыводимым реквизитам и числовым показателям, выбранные поля, отборы,
  сортировка, условное оформление, группировки.

### std674 Заголовок отчета - [its](https://its.1c.ru/db/v8std/content/674/hdoc)
- Отражает цель и содержание; у каждого варианта заголовок заполнен и равен имени варианта.
- Уточнение группировки - во мн. числе без скобок/тире («... по договорам»). Вариант «Основной» запрещен. Избегать
  слова «отчет» в синониме и заголовках. Несколько элементов - заголовок у каждого.

### std675 Отчеты вида "диаграмма" - [its](https://its.1c.ru/db/v8std/content/675/hdoc)
- Только при небольшом объеме данных. Динамика - графики (много периодов), гистограммы (несколько периодов, до 3
  серий), сортировка по периоду. Распределение - гистограмма (менее 10 диапазонов) или график. Структура - круговая
  (до 7-10 частей), вертикальная гистограмма по убыванию (рейтинг менее 10), горизонтальная (более 10).
- Без объемных диаграмм. Цвета стиля `Диаграмма` (70,130,180) и `Прогноз` (199,21,133); красный/зеленый - только для
  негатива/позитива.

### std676 Отчеты вида "таблица", "список" - [its](https://its.1c.ru/db/v8std/content/676/hdoc)
- Вложенность группировок не более 3, от общего к частному; период - в колонках по возрастанию. Уточнения - рядом с
  объектом или отдельной колонкой. Показатели в колонках по важности (или по формуле), в строках - для динамики.
  Порядковый номер - первой колонкой; под печать - макет A4.
- Сортировка - важное сверху; алфавит - когда ищут по наименованию; период - при анализе во времени; только по видимым
  полям.
- Оформление: `НегативноеСобытие` (178,34,34), `ПозитивноеСобытие` (0,128,0), фон `НеактуальнаяИнформация`
  (255,200,200), итоги шрифтом `ИтоговаяИнформация` (жирный), помеченные на удаление - `ПомеченныеНаУдалениеДанные`
  (зачеркнутый); выделять отрицательные, если это ошибка/негатив. Бессмысленные общие итоги (цена в прайсе) отключать.
