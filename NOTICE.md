# Third-party material

## 1С:Библиотека стандартных подсистем (БСП)

Files in `plugins/onec-pack/skills/onec-bsp/references/api/` and `api-index.md` contain method signatures and
documentation comments taken from the source code of «1С:Библиотека стандартных подсистем» 3.2.1.541,
© ООО «1С-Софт», licensed under Creative Commons Attribution 4.0 International
(https://creativecommons.org/licenses/by/4.0/legalcode). Source mirror: https://github.com/1c-syntax/ssl_3_2.

Changes made: only exported methods of the `ПрограммныйИнтерфейс` regions and of `...Переопределяемый` modules were
selected, grouped by subsystem, and comments longer than 60 lines were shortened. The recipe files
(`plugins/onec-pack/skills/onec-bsp/references/*.md`) were written from that source code; they quote short code
fragments under the same license.

## Система стандартов и методик разработки конфигураций (its.1c.ru/db/v8std)

The files in `plugins/onec-pack/skills/onec-v8std/references/` are an independent retelling of the 1C development
