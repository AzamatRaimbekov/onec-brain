# Мозг 1С — onec-pack для Claude Code

Плагин для [Claude Code](https://claude.com/claude-code), который учит Claude разрабатывать на 1С:Предприятие 8.3 по правилам: официальные стандарты 1С, Библиотека стандартных подсистем (БСП), запросы и производительность, интеграции, расширения поверх типовых конфигураций. Плюс сайт «Мозг 1С», где видно, что внутри плагина и на каких данных он построен.

**Сайт:** https://azamatraimbekov.github.io/onec-brain/

| | |
|---|---|
| Стандарты разработки 1С | 321 документ its.1c.ru/db/v8std, пересказ каждого со ссылкой на первоисточник |
| БСП 3.2.1 | 67 подсистем: рецепты встраивания и справочник API на 2982 метода |
| Скиллы | 7: `onec-core`, `onec-code-standards`, `onec-queries`, `onec-integrations`, `onec-extensions`, `onec-bsp`, `onec-v8std` |
| Агенты | `onec-architect` (планирует доработку), `onec-reviewer` (ревью кода) |
| Хук | `check-bsl`: после каждой правки `.bsl` проверяет запросы в цикле, `Сообщить`, модальные вызовы, `Выполнить`, шаблон транзакции, пустое `Исключение`, длину строки |

## Установка

```bash
claude plugin marketplace add AzamatRaimbekov/onec-brain
claude plugin install onec-pack@onec-brain
```

Перезапустите Claude Code. Обновление: `claude plugin marketplace update onec-brain`.

Нужен Node.js 18+ (на нём работает хук `check-bsl`). Отключить хук в проекте: переменная окружения `MDIGITAL_BSL_CHECK=off`.

## Как пользоваться

Пишите Claude обычным языком, плагин сам подгрузит нужные правила:

- «напиши обработку проведения для документа ПоступлениеТоваров»
- «проверь этот модуль по стандартам 1С» — запустится агент `onec-reviewer`, замечания будут с номерами стандартов (`std436`)
- «сделай печатную форму на БСП», «добавь контактную информацию в справочник Партнеры», «ограничь доступ по организации» — рецепты `onec-bsp`
- «спроектируй доработку типовой УТ» — агент `onec-architect`, изменения в расширении
- «что говорит стандарт про временные таблицы?» — конспект `onec-v8std` со ссылкой на its.1c.ru

Плагин рассчитан на работу в Конфигураторе: для больших задач выгрузите конфигурацию в файлы (`Конфигурация → Выгрузить конфигурацию в файлы`) и откройте папку в Claude Code — тогда Claude видит точные имена метаданных и сверяет вызовы БСП с вашей версией библиотеки.

## Сайт «Мозг 1С»

Карта мозга, где каждая точка — стандарт или подсистема БСП. По клику открывается настоящий текст из плагина: конспект стандарта, рецепт встраивания, метод API, скилл или агент. Сайт собирается из файлов плагина, поэтому всегда показывает то, по чему реально работает Claude.

Запустить у себя (без зависимостей, только Node.js):

```bash
git clone https://github.com/AzamatRaimbekov/onec-brain.git
cd onec-brain
npm run site        # http://localhost:4173/site/
```

## Структура

```
.claude-plugin/marketplace.json   маркетплейс onec-brain
plugins/onec-pack/                сам плагин
  skills/<скилл>/SKILL.md         правила и маршрутизация
  skills/onec-v8std/references/   конспекты стандартов + index.md (номер → файл)
  skills/onec-bsp/references/     рецепты БСП, api/ и api-index.md
  agents/                         onec-architect, onec-reviewer
  hooks/hooks.json, scripts/      хук check-bsl
site/                             сайт (React без сборки) — данные строит scripts/build-site.mjs
scripts/                          build-site, serve, test
tests/fixtures/                   примеры BSL для тестов хука
```

## Разработка

```bash
npm test            # хук check-bsl, манифесты, целостность справочников, сборка сайта
npm run check-bsl -- путь/к/выгрузке   # проверить выгруженную конфигурацию
```

После правки скиллов: `npm test`, затем поднимите версию в `plugins/onec-pack/.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` и `package.json` (тест проверяет, что они совпадают). Push в `main` запускает тесты и публикует сайт.
